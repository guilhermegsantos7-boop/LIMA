## Site SENAI

## Descrição do projeto
O projeto envolve o desenvolvimento de uma página institucional para o SENAI, seguindo um wireframe de média fidelidade criado no Figma.

## Objetivo
Apresentar os cursos em destaque e facilitar a navegação dos usuários pelas informações da instituição.

## Tecnologias utilizadas
HTML
CSS3

## Estrutura do site
Cabeçalho com menu de navegação
Área de destaque
Seção de cursos em destaque
Botão "Saiba mais"
Rodapé com área de contato

## Identidade visual
Utilizei o azul-escuro porque transmite confiança e deixa o site mais profissional. O laranja foi utilizado nos botões para chamar a atenção do usuário.

## Explicação do código CSS

Utilizei o display: flex para organizar os elementos lado a lado e o align-items para alinhá-los verticalmente. As propriedades margin e padding foram usadas para ajustar os espaçamentos. Também utilizei object-fit: cover para ajustar as imagens dos cursos e border-radius: 50% para deixar os ícones das redes sociais circulares.

## Como executar
Abrir o arquivo index.html em um navegador.
